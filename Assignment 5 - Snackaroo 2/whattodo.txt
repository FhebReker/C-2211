Design
As before, each dish will be stored as a structure with the following attributes:
    Dish code (eg. 0, 1, 2, 3, 4, etc.)
        Each dish code must be positive and unique. 
        Only integers are acceptable. 
        There is no limit to the number of dishes the database can hold (except memory on the system)
    Dish name (eg. "Spicy Chicken Sandwich", "Kafta Sandwich", "Magic Mushroom Melt", "Brie Burger", "Large 3 Topping Pizza", etc.)
        Only dish names up to 100 characters in length are acceptable (including the null character - So think of this as 99+1).
    Restaurant name (eg. "El Furniture Warehouse", "Barakat Restaurant", "The WORKS Craft Burgers & Beer", "Campus Hi-Fi", "Stobie's Pizza", etc.)
        Only restaurant names up to 100 characters in length are acceptable (including the null character - So think of this as 99+1).
    Average Customer Rating out of 10 (eg. 0.3, 6.5,8.3, 4.9, etc.)
        Only float values between 0.0-10.0 are acceptable. 
        In all reading/writing, consider only one decimal point.
    Price (eg. $5.35, $16.50,$18.30, $42.90, etc.)
        Only positive floats are acceptable. 
        In all reading/writing, consider only two decimal points.

Now, you will also need to store each delivery driver as a structure with the following attributes:
    Driver code (eg. 0, 1, 2, 3, 4, etc.)
        Each driver code must be positive and unique. 
        Only integers are acceptable. 
        There is no limit to the number of drivers the database can hold (except memory on the system)
    Driver name (eg. "Al Dente", "Sue Shi", etc.)
        Only names up to 50 characters in length are acceptable (including the null character - So think of this as 49+1)
    Vehicle colour
        Only the colours "red", "green", "blue", "grey", "white", "black", and "other" are acceptable. 
        To simplify user input, use the integers 0 - 6 to represent one of the 7 possible colours (0 == "red", 1 == "green", etc.).
    Licence Plate
        Only 2-8 alphanumeric characters and space are acceptable

Your program will then use a linked list of structures to represent all dishes and a linked list of structures to represent all drivers.




Implementation
Your program should continuously prompt the user for one of four possible commands:

    Print help (using command h)
        Print a simple message or messages describing how to use the program.
    Quit (using command q)
        Quit the program. Yes, all data is lost when quitting your program. 
        You do not need to maintain the data across multiple runs.
    Control dishes (using command m)
        See below
    Control drivers (using command a)
        See below



Dishes
As in snackaroo.c (Assignment 4) all the same commands exist as before:

    Insert a new dish (using the command i)
        Prompt the user for the dish code
            Assume the user will enter one integer
            This must be unique in your database and cannot conflict with an existing dish code. 
            If the number is less than 0, or if there is a conflict with an existing code, or if the database is full, tell the user the error. 
            The user can try again or you can return the user to the main prompt
        Prompt the user for the name of the dish
            Assume the user will enter a string of characters of any length
            If the dish name is longer than the acceptable length, you should accept as many characters as you can and ignore any additional characters. 
            If there is any other issue, tell the user the error. 
            The user can try again or you can return the user to the main prompt.
        Prompt the user for the name of the restaurant
            Assume the user will enter a string of characters of any length
            If the dish name is longer than the acceptable length, you should accept as many characters as you can and ignore any additional characters. 
            If there is any other issue, tell the user the error. 
            The user can try again or you can return the user to the main prompt.
        Prompt the user for the dish rating
            Assume the user will enter one float value with one decimal point
            If the rating is not in the range 0.0-10.0, the user can try again or you can return the user to the main prompt
        Prompt the user for the dish price
            Assume the user will enter one float value with two decimal points
            If the price is not a positive float value, the user can try again or you can return the user to the main prompt
    Search for a dish in the database and print it out (using the command s)
        Prompt the user for the dish code
            If the dish code is found, print out all the values for this dish only (see the print command below for more details)
            If the dish code is not found, tell the user the error. 
            The user can try again or you can return the user to the main prompt
    Update a dish in the database (using the command u)
        Prompt the user for the dish code
            If the dish code is found, prompt the user to update all the values for the dish (see the insert command above for details)
            If the dish code is not found, tell the user the error. 
            The user can try again or you can return the user to the main prompt
    Print the entire list of dishes (using the command p)
        Print out a table listing all the dishes in your database with all the attributes:
            Dish Code
            Dish Name
            Restaurant Name
            Dish Rating
            Dish Price

    You should implement one additional command:
    Erase dish (using command e)
        Prompt the user for the dish code
            If the dish code is found, erase the dish safely by removing the element from the linked list and freeing the memory
            If the dish code is not found, tell the user the error. 
            The user can try again or you can return the user to the main prompt
